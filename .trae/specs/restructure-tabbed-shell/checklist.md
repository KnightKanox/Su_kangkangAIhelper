# Checklist

## 信息架构
- [x] Android 底部与 Windows 顶部均有「首页 / 食养 / 我的」三个 Tab，名称一致
- [x] Tab 切换后已填答案、体质结果、节气选择与推荐结果均保留，不触发重新请求
- [x] 问卷页与画像页为全屏二级页，可返回进入前的 Tab
- [x] 首页完整展示原问候语（逐字一致），主 CTA 按「未答题 / 已出体质未确认 / 已有推荐」切换
- [x] 首页已有推荐时显示第一道菜预览，点击进入食养 Tab
- [x] 「我的」展示体质卡、可折叠画像摘要、问卷摘要（未提供显示「未提供」）与重新填写入口

## 结构化推荐
- [x] 食养页展示 3 张独立菜谱卡，每张含菜名、菜系、主料、做法摘要、推荐理由与「食养参考」标签
- [x] 菜谱卡的字段数据来自本地 CSV，未由模型编造
- [x] 「展开更多」可在卡内展开完整做法与食养特点，并可再次收起
- [x] 忌口提示字段为空时不显示该行，也不生成「无忌口」等文案
- [x] DeepSeek 仅生成推荐理由；按菜名回填，未匹配或调用失败时使用本地理由
- [x] 无网络时 3 张卡片仍完整显示（含本地理由），流程不阻塞
- [x] 免责声明「本推荐为食养参考，不构成医疗建议」固定展示且不依赖模型输出
- [x] 推荐区不出现原始 Markdown 标记；画像摘要仍正常渲染 Markdown

## 空态与异常
