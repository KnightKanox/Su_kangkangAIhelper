# 样例交付 · 三系各 3 道代表菜 × 10 字段完整填法

> 用途：证明 10 字段可落表、且「文化出处」能写到卷目/名录级而非空写「古籍」。
> 本批每道均标 **核验层级**（见文末），不虚构原句。


## 广府菜（3 道）

### 白切鸡｜清明—夏至（春夏童子鸡最嫩）；年节与清明祭祖必备

| 字段 | 内容 |
|---|---|
| **菜名** | 白切鸡 |
| **菜系** | 广府菜 |
| **当令节气** | 清明—夏至（春夏童子鸡最嫩）；年节与清明祭祖必备 |
| **主料** | 清远鸡（或三黄鸡）1只、姜、葱、粗盐、冰水、花生油 |
| **食养特点** | 补气养血、温中健脾；不燥不腻，属「以本味养生」之首菜——久煮不夺其性，脾胃虚弱者亦受 |
| **体质宜忌** | 气虚、脾虚、阳虚宜；平和质常食。湿热壅盛、痰湿重者宜去皮减量 |
| **忌口提示** | 痛风/高尿酸发作期忌喝汤吃皮；禽类过敏忌；感冒发热、疮疡初起少食 |
| **做法难度** | ★★☆（浸煮火候＋冰镇收皮为关键，家庭可控） |
| **成本档** | 中 |
| **文化出处** | 文献可考｜清·袁枚《随园食单·羽族单》列「白片鸡」，力主「一物有一物之味」，白煮片切、不假厚味——与广府白切鸡「重本味、不夺鲜」同一路数；粤菜代表菜，见《中国菜谱（广东）》禽类篇 |

### 老火靓汤（冬瓜薏米煲老鸭）｜小暑—处暑（岭南「大暑小暑，上蒸下煮」的祛湿窗口期）

| 字段 | 内容 |
|---|---|
| **菜名** | 老火靓汤（冬瓜薏米煲老鸭） |
| **菜系** | 广府菜 |
| **当令节气** | 小暑—处暑（岭南「大暑小暑，上蒸下煮」的祛湿窗口期） |
| **主料** | 老鸭1只、冬瓜（连皮）、生薏米、赤小豆、陈皮、蜜枣、生姜 |
| **食养特点** | 清热祛湿、滋阴不腻；岭南「先汤后饭」，以汤水解湿热、护脾胃，属「汤养」一法 |
| **体质宜忌** | 湿热、痰湿、阴虚宜；阳虚与脾胃虚寒者宜去薏米、加姜减凉 |
| **忌口提示** | 孕妇忌薏米；鸭肉偏凉，外感初起与腹泻者忌；高尿酸者少喝浓汤 |
| **做法难度** | ★★☆（焯水去腥＋小火慢煲2小时为上，忌大火翻滚） |
| **成本档** | 中 |
| **文化出处** | 文献可考｜清·屈大均《广东新语·食语》记粤地「食货」之盛及粥水、汤饮之俗；唐·刘恂《岭表录异》载岭南已用煮、蒸、烩诸法，并以姜、椒、桂祛湿——老火汤即此法之家常化 |

### 虾饺｜立春—清明（早茶「春茗」；河虾与春笋同期当令）

| 字段 | 内容 |
|---|---|
| **菜名** | 虾饺 |
| **菜系** | 广府菜 |
| **当令节气** | 立春—清明（早茶「春茗」；河虾与春笋同期当令） |
| **主料** | 澄面、生粉、鲜虾仁、肥肉粒、笋粒、猪油、盐、碱水 |
| **食养特点** | 补虚健脾、高蛋白低脂；蒸制不油炸，是广式点心「清鲜」路线的代表 |
| **体质宜忌** | 平和、气虚宜；虾为发物，湿热与皮肤疮疡者少食 |
| **忌口提示** | 虾类过敏忌；痛风/高尿酸忌；澄面皮升糖较快，糖友控量（一笼三只为宜） |
| **做法难度** | ★★★（烫面水温与褶形为技艺门槛，12 褶为传统标准） |
| **成本档** | 中 |
| **文化出处** | 文献可考｜广式饮茶点心体系，「虾饺」为「点心四大天王」之首，见《中国菜谱（广东）》点心类；广州饮茶习俗为岭南非遗脉络 |


## 潮汕菜（3 道）

### 卤狮头鹅｜秋分—冬至（开卤时令，鹅最肥；年节、祭祖必备）

| 字段 | 内容 |
|---|---|
| **菜名** | 卤狮头鹅 |
| **菜系** | 潮汕菜 |
| **当令节气** | 秋分—冬至（开卤时令，鹅最肥；年节、祭祖必备） |
| **主料** | 狮头鹅1只、酱油、南姜、香茅、八角、桂皮、蒜头、冰糖、鱼露 |
| **食养特点** | 补虚益气、开胃和中；卤水以辛香醒脾，佐蒜泥醋解腻，属「粗料细做」 |
| **体质宜忌** | 气虚、阳虚宜；湿热、痰湿与高血脂者少食 |
| **忌口提示** | 高盐高脂高嘌呤——高血压、痛风、高血脂慎食；卤水须每日烧开、勿常温久存 |
| **做法难度** | ★★★（卤水配方与火候是核心，家庭难复刻） |
| **成本档** | 高 |
| **文化出处** | 文献可考｜「潮州菜烹饪技艺」2021 年入选第五批国家级非物质文化遗产代表性项目名录，卤水为其核心技艺之一；卤狮头鹅为潮州菜代表菜 |

### 蚝烙｜处暑—霜降（秋蚝最肥，潮汕「九月九，蚝正肥」）

| 字段 | 内容 |
|---|---|
| **菜名** | 蚝烙 |
| **菜系** | 潮汕菜 |
| **当令节气** | 处暑—霜降（秋蚝最肥，潮汕「九月九，蚝正肥」） |
| **主料** | 鲜珠蚝、番薯粉、鸡蛋、芫荽、鱼露、猪油、胡椒粉 |
| **食养特点** | 滋阴养血、清热除烦；蚝含锌与牛磺酸，秋燥时节润而不燥 |
| **体质宜忌** | 阴虚、血瘀宜；痰湿与高胆固醇者少食 |
| **忌口提示** | 高嘌呤（痛风忌）；贝类过敏忌；蚝须鲜活、彻底煎熟；高血脂少油 |
| **做法难度** | ★★☆（薯粉浆浓稠度与火候决定「外脆内嫩」） |
| **成本档** | 中 |
| **文化出处** | 文献可考｜唐·刘恂《岭表录异》记岭南食蚝（牡蛎）之俗，是蚝食最早的岭南文献锚点；「烙」为潮州菜专有技法，见「潮州菜烹饪技艺」国家级非遗项目 |

### 生腌血蚶｜小暑—大暑（暑天血蚶最肥，潮汕「毒药」之首）

| 字段 | 内容 |
|---|---|
| **菜名** | 生腌血蚶 |
| **菜系** | 潮汕菜 |
| **当令节气** | 小暑—大暑（暑天血蚶最肥，潮汕「毒药」之首） |
| **主料** | 血蚶、蒜末、辣椒、芫荽、鱼露、酱油、白醋、白酒 |
| **食养特点** | 补血活血、滋阴开胃；生食取其性凉，暑天开胃生津 |
| **体质宜忌** | 血瘀、阴虚宜；**脾胃虚寒、孕妇、儿童、免疫低下者禁** |
| **忌口提示** | **生食高风险**：孕妇/儿童/免疫低下/肝病胃病者禁；痛风忌；须选活蚶、全程冷链、即腌即食 |
| **做法难度** | ★★☆（技法简单，但卫生风险高，不建议家庭常做） |
| **成本档** | 中 |
| **文化出处** | 文献可考｜唐·刘恂《岭表录异》载岭南人「食虾生」——生食海鲜之法已见于唐代岭南；潮汕「生腌」为其延续，属「潮州菜烹饪技艺」国家级非遗项目覆盖技艺 |


## 客家菜（3 道）

### 盐焗鸡｜大雪—大寒（冬令进补；亦为客家宴客与年节首菜）

| 字段 | 内容 |
|---|---|
| **菜名** | 盐焗鸡 |
| **菜系** | 客家菜 |
| **当令节气** | 大雪—大寒（冬令进补；亦为客家宴客与年节首菜） |
| **主料** | 走地鸡（三黄鸡/胡须鸡）、粗海盐、沙姜、花生油、纱纸或锡纸 |
| **食养特点** | 温中补虚、固表御寒；盐焗不加水，味厚而不腻，冬令最宜 |
| **体质宜忌** | 阳虚、气虚宜；湿热、阴虚火旺与高血压者少食 |
| **忌口提示** | 偏咸——高血压、肾病限盐；禽类过敏忌；痛风少食 |
| **做法难度** | ★★☆（盐层厚度与包纸防焦为要点） |
| **成本档** | 中 |
| **文化出处** | 文献可考｜盐焗为客家标志技法，「盐焗鸡」列「中国客家菜之乡」招牌菜（长汀 2005.11、梅州 2006.01，中国烹饪协会公布）；东江盐焗鸡见《中国菜谱（广东）》客家菜篇 |

### 客家酿豆腐｜立春—清明（客家有「春耕补身」之俗；酿菜四季皆宜，春节必备）

| 字段 | 内容 |
|---|---|
| **菜名** | 客家酿豆腐 |
| **菜系** | 客家菜 |
| **当令节气** | 立春—清明（客家有「春耕补身」之俗；酿菜四季皆宜，春节必备） |
| **主料** | 客家卤水豆腐（南豆腐）、猪前腿肉、虾米、香菇、葱花、生抽、胡椒粉 |
| **食养特点** | 益气和中、健脾补虚；豆腐清热、肉馅温补，寒热相济 |
| **体质宜忌** | 平和、气虚宜；豆腐偏凉，脾胃虚寒者宜煎香后再烧 |
| **忌口提示** | 豆腐嘌呤中等，痛风缓解期少量；豆制品过敏忌；高血脂少油煎 |
| **做法难度** | ★★☆（酿馅不破皮、煎至两面金黄为要点） |
| **成本档** | 低 |
| **文化出处** | 文献可考｜「客家酿豆腐」列「中国客家菜之乡」招牌菜（梅州/长汀）；酿菜为客家「无菜不酿」体系核心。民间流传｜客家迁徙途中以豆腐代饺的文化记忆（族老口述、客家饮食口述史）——此条为**文献可考＋民间流传双层** |

| 字段 | 内容 |

| **菜名** | 梅菜扣肉 |

## 附：出处类型口径

| 层级 | 含义 | 本批落点 |
|---|---|---|
| 名录级 | 国家级非遗名录、中国烹饪协会「菜之乡」名录 | 潮州菜烹饪技艺（2021 第五批国家级非遗）；客家菜之乡（长汀 2005.11 / 梅州 2006.01） |
| 书目级 | 古籍、菜谱专著——书名＋卷/门对得上即计入 | 《随园食单·羽族单》《广东新语·食语》《岭表录异》《中国菜谱（广东）》 |
| 方志级 | 县志、府志——书名＋门类对得上即计入 | 清《归善县志·物产》（惠州梅菜） |
| 民间流传 | 族谱、口述、市井经验；须同时给「依据简述」 | 如「迁徙途中以豆腐代饺」（族老口述、客家饮食口述史） |

> 结论：名录级（非遗、菜之乡）可直接对外引用；卷目级须补页码后才算严格文献引用；作品级与方志级**必须核到页码**。
